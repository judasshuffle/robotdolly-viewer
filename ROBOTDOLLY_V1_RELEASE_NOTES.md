# ROBOTDOLLY Viewer v1 — Experimental Preview

**Windows 64-bit — early test build, not an official Second Life viewer release.**

ROBOTDOLLY explores a Blender-inspired approach to Second Life, with flexible, independently selectable workspace areas.

## In this preview
- Split workspace areas horizontally or vertically.
- Drag dividers to resize areas.
- Join adjacent simple areas.
- Choose World, Chat, Inventory or Empty as an area's content.
- Navigate nested editor categories and a starter Favourites menu.
- Separate AREA menu for layout operations.

## Known limitations
- This is experimental software; the opening screen and layout need further polish.
- Join operations do not yet handle every nested layout.
- Workspace layouts are not saved between sessions.
- Multiple independent 3D world cameras are not yet implemented.
- Branding is incomplete (including icons); the viewer may show upstream test graphics.
- The Windows installer is not code-signed and has not yet been validated on a clean Windows PC.

## Tester checklist
1. Install and launch on Windows 64-bit, ideally on a test machine.
2. Confirm it does not overwrite settings for your usual Second Life viewer.
3. Log in and test World, Chat, Inventory, area splitting, dragging and joining.
4. Report crashes, overlapping controls, login failures or installer/uninstaller issues.
